# Vidal Bar Genius

A full-stack cocktail recipe and home bar management app that helps users track ingredients, discover drinks they can make, save recipes, and build shopping lists.

## Features

- Manage a personal home bar inventory
- Match available ingredients to cocktail recipes
- View drinks that are ready to make now
- See recipes that are missing only one ingredient
- Save favorite recipes
- Generate shopping lists for missing ingredients
- Upgrade flow with Stripe
- Persistent database-backed user data

## Tech Stack

- Next.js
- React
- Prisma
- SQLite / PostgreSQL
- REST APIs
- Stripe
- Vercel
- GitHub
